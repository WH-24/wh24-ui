Обзор

#overview
Wowhaus Wiki UI

Этот документ — “эталон” текущих UI-решений: токены, типографика и ключевые компоненты. Его цель — быстро сравнивать/поддерживать консистентность и ускорять разработку.

⌘ Cmd+K / Search ⌘ K

Источник UI-стилей: общий CSS из `admin-mockup.html`, вынесенный в `styleguide/assets/ui.css`.

Tip: кнопка Theme переключает light/dark (сохраняется в localStorage).

Связанные мокапы
Hub Browser Search Cmd+K Article Editor Images Admin

Токены и базовая типографика в этих мокапах совпадают. Странице style guide достаточно `ui.css` для общих компонентов; у некоторых страниц (Editor / Cmd+K / Search / Article) есть дополнительные page-specific правила внутри их HTML.

# UI Style Guide (benchmark)

Открывайте `styleguide/index.html` — это автономная страница-эталон UI (токены, типографика, компоненты) на **реальных стилях** проекта.

## Что внутри

- `assets/ui.css` — вынесенный CSS из `admin-mockup.html` (источник правды по текущему виду).
- `assets/styleguide.css` — стили только для компоновки документа.
- `assets/styleguide.js` — мелкие интеракции (подсветка навигации, demo-модалка).

## Как обновлять

Если меняете стили в `admin-mockup.html`, обновите соответствующий блок в `assets/ui.css` (или скажите мне — я синхронизирую автоматически).

## Бриф: иконки, фавиконы, бренд‑ассеты (Wowhaus Wiki UI)

### Цели
- **Единый визуальный язык иконок** для UI (навигация, действия, статусы).
- **Убрать emoji** из UI‑контролов; перейти на один целостный набор.
- Обеспечить работу ассетов в **светлой и тёмной теме** + поддержку семантики состояний (neutral / info / warn / bad).

### Результат (deliverables)
- **Набор иконок (SVG)**: основные UI‑иконки, экспортированные отдельными SVG‑файлами.
- **Набор фавиконов**:
  - `favicon.ico` (мульти‑размерный, если возможно)
  - `favicon-16.png`, `favicon-32.png`, `favicon-48.png`
  - `apple-touch-icon.png` (180×180)
  - `android-chrome-192.png`, `android-chrome-512.png`
- Опционально: вариации знака/иконки приложения (монохром / filled).

### Спецификация икон‑системы
- **Сетка / размеры**:
  - Базовые размеры: **16, 20, 24**
  - Опционально: 12 для микро‑лейблов (только если действительно нужно)
- **Штрих (stroke)**:
  - Одна согласованная толщина штриха на семейство размеров (предложить дизайнеру).
  - Скруглённые окончания/соединения (рекомендуется) для дружелюбного B2B UI.
- **Геометрия**:
  - Оптическое выравнивание (не только геометрическое центрирование).
  - Pixel‑hinting / чёткие края на 1×.
- **Стиль**:
  - Предпочтительно outline‑иконки для большинства UI.
  - Filled‑вариант — только когда нужен (например, active star/bookmark), но в рамках общей системы.

### Цвет и темы
- Иконки по умолчанию должны быть **монохромными** и наследовать цвет текста (правило разработки: `currentColor`).
- Для статусных иконок (если появятся) допускается управляемая раскраска через токены:
  - `--good`, `--info`, `--warn`, `--bad`
- В тёмной теме иконки должны иметь достаточный контраст (без полупрозрачных штрихов, которые “пропадают”).

### Состояния интерактива
Для иконок внутри контролов состояния задаёт контейнер, но иконка должна оставаться читаемой:
- default / hover / active / disabled
- disabled: совместимо с `--disabled-opacity`

### Нейминг и экспорт
- Имена файлов: `kebab-case.svg` (например `settings.svg`, `bell.svg`, `chevron-down.svg`)
- Каждый SVG:
  - корректный/чистый `viewBox`
  - без “захардкоженных” цветов для дефолтных иконок (использовать `currentColor`)
  - оптимизирован (SVGO или аналог)

### Приоритетный список иконок (стартовый)
- Навигация: `home`, `search`, `tag`, `users`, `settings`, `arrow-left`
- Действия: `plus`, `edit`, `trash`, `check`, `x`, `dots`, `filter`, `sort`, `copy`
- UI: `chevron-down`, `chevron-right`, `external-link`, `info`, `warning`, `error`

### Чеклист приёмки
- Единый стиль во всех иконках (штрих, скругления, оптический вес).
- Хорошо выглядит в light и dark теме.
- Экспорт соответствует неймингу + правилу `currentColor`.
- Иконки хорошо читаются на 16px.

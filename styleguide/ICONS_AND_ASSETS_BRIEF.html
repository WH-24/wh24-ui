Обзор

#overview
Бриф: иконки, фавиконы, бренд‑ассеты

Wowhaus Wiki UI · документ для дизайна/экспорта ассетов

Цели
  • Единый визуальный язык иконок для UI (навигация, действия, статусы).
  • Убрать emoji из UI‑контролов; перейти на один целостный набор.
  • Поддержка светлой и тёмной темы + семантики состояний (neutral / info / warn / bad).

Поставка

#deliverables
  • Набор иконок (SVG): основные UI‑иконки, экспортированные отдельными SVG‑файлами.
  • Набор фавиконов:
    • favicon.ico (мульти‑размерный, если возможно)
    • favicon-16.png, favicon-32.png, favicon-48.png
    • apple-touch-icon.png (180×180)
    • android-chrome-192.png, android-chrome-512.png
  • Опционально: вариации знака/иконки приложения (монохром / filled).

Спецификация

#spec
Сетка / размеры
16 20 24 опц. 12

Опциональный 12px — только при реальной необходимости (микро‑лейблы/очень плотные таблицы).

Штрих / геометрия
  • Одна согласованная толщина штриха на семейство размеров.
  • Rounded caps/joins — рекомендуется.
  • Оптическое выравнивание + pixel‑hinting на 1×.
Стиль
  • По умолчанию — outline‑иконки.
  • Filled‑вариант — только по смыслу (например, активный bookmark), но в рамках общей системы.

Цвет и темы

#color
  • Иконки по умолчанию — монохром, наследуют цвет текста: currentColor.
  • Для статусных иконок допускается раскраска токенами: --good, --info, --warn, --bad.
  • В тёмной теме не использовать полупрозрачные штрихи, которые “пропадают”.

Пример (как должно выглядеть в UI)

#example
Иконка внутри кнопки (монохром, currentColor)
Статусная окраска (только там, где есть смысл)
✓ good i info ! warn × bad
Требования к SVG (snippet)
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" ...> ... </svg>

Важно: дефолтные иконки — без захардкоженных цветов, только currentColor.

Нейминг и экспорт

#export
  • Имена файлов: kebab-case.svg (например settings.svg).
  • Каждый SVG:
    • чистый viewBox
    • без “захардкоженных” цветов (использовать currentColor)
    • оптимизирован (SVGO или аналог)

Чеклист приёмки

#checklist
  • Единый стиль (штрих, скругления, оптический вес).
  • Хорошо выглядит в light и dark теме.
  • Экспорт соответствует неймингу и правилу currentColor.
  • Читаемо на 16px.

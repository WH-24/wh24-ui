# Wowhaus Wiki — Сводка по мокапам

## Концепция

Внутренняя вики архитектурного бюро. Не «база документов», а **граф знаний с типизированным контентом и ролевой моделью**: проекты, стандарты, решения и статьи живут вместе и связаны wikilink'ами. Поиск, ревью и compliance — не отдельные приложения, а слои поверх единой ленты.

| Экран | Файл | Роль в продукте |
|---|---|---|

## Дизайн-система

- **Шрифт:** Manrope (400/500/600/700) + ui-monospace для кода/логов.
- **Палитра:** терракотовый акцент (`#dd6731`) поверх тёплых cream-фонов; статусные `--good/warn/info/bad` с -bg/-bd-вариантами.
- **Типы контента — каждый со своим цветом:**
  - Проект `#8e3a14` — теплый коричневый (▤)
  - Стандарт `#444441` — графит (⬚)
  - Решение `#0c447c` — синий (◇)
  - Статья `#3c3489` — фиолетовый (¶)
- **Hairline 0.5px** вместо 1px-границ; `backdrop-filter: blur(8px)` для прозрачных шапок; `font-variant-numeric: tabular-nums` для всех чисел в таблицах.
- **Радиусы:** 5 / 7 / 10 / 12 / 999px.
- **Box-shadow редко** — только hover карточек и модалы.

## Роли и доступы

| Роль | Что может |
|---|---|
| **Гость** | Read-only по ссылке, видит только проекты |
| **Редактор** | Создаёт статьи, отправляет на ревью |
| **Менеджер** | Ревьюит, публикует, мерж тегов, compliance, доступы, аналитика, **одобряет фасеты** |
| **Администратор** | Всё что менеджер + **Корзина**, API health, Логи, Backup |

В админке — toggle М↔А, при переключении на Менеджера админ-only вкладки автоматически редиректят на Дашборд.

## Ключевые механики

- **BP-флаг** (Best Practice) — мета-метка на любом материале, выделена в карточке и обложке.
- **Wikilinks** vs **inline-теги** — разные сущности, визуально различимы: wikilink — terra-чип с `⤷`, тег — пунктирное подчёркивание `#`.
- **Фасеты проекта** — селектор: Год (date-range или «в работе»), Площадь (string), Страна/Город/Типология/Стадия/Заказчик (выбор из списка с предложением нового → на одобрение менеджеру).
- **Команда (Crew)** — компактный список из WH_ID, специфичен для проектов.
- **Compliance** — Стандарты могут требовать подтверждения ознакомления с дедлайном; покрытие отслеживается на админке.
- **Очередь ревью** — кнопка «Вернуть с комментарием» открывает inline-форму с quick-reply chips («Нужны источники», «Уточнить терминологию», …).
- **Чек-лист** — интерактивный с counter-ом «N из M выполнено» (специфика стандартов).
- **Onboarding** — маршруты по ролям, личные карточки новичков с трекингом «застрял на N-й день».
- **⌘K — только функции**: переходы + UI-команды (Сменить тему, Скопировать ссылку, Свернуть боковую панель). Полнотекстовый поиск делегирован Поиску.
- **Edit-mode**: Tilda-style `+` между блоками открывает левый сайдбар с превью пресетов; floating-toolbar над выделением; кнопки Превью / Сохранить (черновик) / Отправить на ревью.

## Темы

Light по умолчанию, Dark через `html[data-theme="dark"]` с инвертированной палитрой (терракот сохраняется — работает на тёмном). Состояние в `localStorage['wh-theme']` — общее для всех мокапов.

## Связность

Все 9 мокапов связаны навигационно:
- Логотип → хаб (везде)
- ⌘K-pill → cmdk (везде кроме самой палитры и edit-режима)
- Админ-кнопка → admin-panel (справа сверху)
- Карточки/строки результатов в browser/search/cmdk → соответствующая статья (по типу: std → article-std, остальные → article)
- Backlinks, embeds, wikilinks внутри статей → соответствующая статья (по типу)
- В админке очередь ревью «Открыть» → нужный article-view; compliance-row → article-std
- Drawer-источник в Images → статья-владелец изображения
- В edit-режиме «Превью» → article-mockup в новой вкладке; «Отправить на ревью» — модал с handoff на админку

## Технические факты

- 9 standalone HTML-файлов, всё inline (CSS+JS внутри `<style>`/`<script>`)
- Размеры: от 24 KB (cmdk) до 145 KB (admin)
- Только Manrope из Google Fonts CDN — никаких других внешних ресурсов
- JS — минимальный, только toggle классов и видимости (никаких real запросов, state-менеджмента, валидации)
- Mobile-адаптация: media-queries на 1100/880/720/540 px; на узких viewports таблицы админки переходят в `overflow-x:auto`
- Styleguide-эталон в `styleguide/index.html` — отдельная страница с токенами и компонентами на реальных стилях

## Что вне скоупа мокапов

- SVG-иконки и фавиконы — отдельный бриф [`styleguide/ICONS_AND_ASSETS_BRIEF.md`](styleguide/ICONS_AND_ASSETS_BRIEF.md) для дизайнера
- Реальная бизнес-логика — задача стадии разработки (`wiki-web`)
- Отдельные view для Гостя / Редактора — текущая админка показывает только М↔А

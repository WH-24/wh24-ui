# Changelog

Все заметные изменения в wh-ui фиксируются здесь. Формат — [Keep a Changelog](https://keepachangelog.com/),
версионирование — [SemVer](https://semver.org/).

Каждый пакет (`@wowhaus-24/ui-tokens`, `@wowhaus-24/ui-react`) бампается
независимо. В разделе версии указывается какие пакеты затронуты.

## [Unreleased]

### Added — `@wowhaus-24/ui-react`
- `AppShell`: параметр `showTopbar` (по умолчанию `true`). Модуль, который
  открывается внутри портала, теперь может не рисовать свою шапку — у портала
  прямо над ней уже есть своя, с тем же логотипом, строкой поиска и аватаром.
- `ListPage`: у колонки появился флаг `primary` — им помечают колонку названия,
  и она не сжимается уже 350px (`NAME_COL_MIN_WIDTH`, экспортируется). Раньше
  название жило на общем минимуме 150px и обрезалось многоточием, хотя соседние
  «Год» и «Город» стояли свободно. Минимум держит в обоих режимах раскладки: при
  прокрутке колонке отдаётся её минимум в px, а если процент из `width` не
  дотягивает до минимума (34% на узком контейнере — это ~330px), список целиком
  переходит на px-минимумы, и лишнее место браузер раскладывает сам.

### Fixed — `@wowhaus-24/ui-react`
- `ListPage`: колонки с `defaultHidden`, приходящие после маунта (из асинхронных
  источников — справочники, доп-поля), больше не вылезают в таблицу сами по
  себе. `known`-список настроек уважается только после явного «Применить»
  (`own=true`), а пустая «общая» настройка колонок (авто-созданная запись)
  больше не затирает дефолтные скрытия.

### Added — `@wowhaus-24/ui-react`
- `FilterBar`/`Combobox`: у опции фильтра появились `avatar`/`initials` — в
  мультивыборе перед подписью рисуется аватарка (фото или инициалы). Нужно для
  фильтров-списков сотрудников.

### Added — `@wowhaus-24/ui-react`

- `ListPage`: настройка колонок — шестерёнка в конце шапки таблицы открывает
  список колонок с галочками (показать/скрыть). Выбор запоминается для
  пользователя (localStorage, по `scope` фильтра). Последнюю видимую колонку
  скрыть нельзя; служебные колонки без заголовка (например аватар) всегда видимы.

### Fixed — `@wowhaus-24/ui-react`

- `FilterBar`: панель «Добавить поле» больше не обрезает верхние поля, когда их
  много. Раньше сетка позиционировалась абсолютно от низа с фиксированной высотой
  и вылезала над поповером (`overflow: hidden` резал верх, докрутить до него было
  нельзя). Теперь высота панели ограничена размером поповера и список скроллится
  целиком; сам поповер стал выше, чтобы за раз помещалось больше полей.

### Changed — `@wowhaus-24/ui-react`

- `ListPage`: в режиме карточек постраничная навигация заменена на подгрузку по
  скроллу — карточки догружаются по мере прокрутки, без ограничения «страницей».
  Если список помещается на экран целиком — подгружается сразу весь, а не
  застревает на второй порции. Таблица листается кнопками «Назад/Далее».
- `ListPage`: проп `defaultView` — стартовый режим показа (таблица/карточки).
  Выбор пользователя запоминается (localStorage по scope фильтра) и перекрывает
  умолчание.
- `FilterBar`: фильтр, отмеченный булавкой «по умолчанию», показывается первым в
  списке фильтров — раньше он стоял на своём месте в общем порядке, и его
  приходилось искать глазами. Порядок остальных не меняется.
- `FilterBar`: применённые условия фильтра (без сохранённого пресета) теперь
  показываются чипами прямо в строке поиска («Поле: значение»), у каждого свой
  крестик для сброса. Раньше в строке отображалось только название пресета, и
  ad-hoc фильтры были не видны при закрытой панели.

### Added — `@wowhaus-24/ui-tokens@0.1.0`, `@wowhaus-24/ui-react@0.1.0`

- Первичный scaffold монорепо.
- `tokens.css` с полной палитрой Wowhaus (terra, ink, surf, type colors,
  status tones), радиусы, шрифты.
- Тёмная тема через `html[data-theme="dark"]`.
- `base.css` — минимальный reset.
- `tokens.ts` — типизированный экспорт CSS-переменных + типы
  `ArticleType`, `StatusTone` со словарями цветов.
- `theme.ts` — vanilla API: `initTheme`, `setMode`, `setTheme`,
  `toggleTheme`, `getTheme`, `getMode`, `subscribe`. Поддержка
  `'light' | 'dark' | 'system'`, persistence в localStorage,
  cross-tab синхронизация, реакция на `prefers-color-scheme`.
- `ThemeProvider` + `useTheme` для React.
- Мокапы (8 экранов) перенесены из `~/Desktop/WH_PRESENTATION/Mocups/`.
- Styleguide перенесён.
- CI workflow (typecheck + build на push/PR в main).
